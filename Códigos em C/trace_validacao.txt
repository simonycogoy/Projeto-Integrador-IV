# trace_validacao.txt — Trace de Validacao Controlado
#
# Cache L1: 4KB | bloco=32B | 2 vias | 64 conjuntos
#   offset=5 bits | index=6 bits | tag=21 bits
#
# Todos os enderecos abaixo mapeiam no CONJUNTO 0 da L1:
#   indice = bits[10:5] do endereco
#   Para conjunto 0: endereco & 0x7E0 == 0x000
#
# Enderecos usados:
#   A = 0x00000000  tag=0  conj=0
#   B = 0x00000800  tag=1  conj=0
#   C = 0x00001000  tag=2  conj=0
#   D = 0x00001800  tag=3  conj=0  ← so existe para forcar thrashing
#   HOT = 0x10000000  tag=alto  conj=0  ← dado quente
#
# Com 2 vias, apenas 2 blocos cabem no conjunto 0 ao mesmo tempo.
#
# CENARIO: Thrashing classico LRU vs DRRIP
#
# FASE 1 — Warmup: carrega A e HOT na cache
# FASE 2 — Scan: acessa B, C, D em sequencia (expulsa tudo no LRU)
# FASE 3 — Verifica: acessa HOT de novo (HIT no DRRIP, MISS no LRU)
# FASE 4 — Repete para mostrar diferenca acumulada
#
# RESULTADOS ESPERADOS (L1):
#   LRU  : ~25-35% de acertos  (HOT sempre expulso pelo scan)
#   DRRIP: ~45-60% de acertos  (HOT sobrevive com RRPV=0)
# ============================================================
